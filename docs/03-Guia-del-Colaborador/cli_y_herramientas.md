# Interfaz De Linea De Comandos (CLI) Y Herramientas

Este documento detalla la interfaz de linea de comandos, las herramientas auxiliares y la integracion de desarrollo para **Bagron**.

---

## Sintaxis General Del CLI

El CLI permite compilar, ejecutar y gestionar el compilador:

```bash
vnma run main.py <archivo.bg>
```

---

## Herramientas

- **Gram:** Motor sintáctico de Bagron para análisis léxico y gramatical BNF.
- **vnma:** Gestor de dependencias y entornos reproducibles para el desarrollo del compilador.
