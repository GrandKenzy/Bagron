# Integración AOT de Gram en Bagron

- Añadidos los intrínsecos internos `__bagron_argc()` y
  `__bagron_arg_copy(index, buffer, capacity)` para que el CLI generado por
  Gram pueda recibir argumentos sin cambiar la sintaxis `func main() int32`.
- El wrapper nativo conserva `argc/argv` para Windows y Linux; macOS produce
  un diagnóstico explícito de target no soportado.
- Las cláusulas condicionales de target se preprocesan antes de resolver
  `System` y `Arch`, evitando seleccionar siempre la primera rama textual.
- El dominio `extern bagron` se mantiene dentro del módulo final y no se
  convierte en una dependencia externa del linker.
